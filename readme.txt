SEO Engineering monitoring agent with crawl, history, scoring, exports and email reporting.

== Description ==

JM SEO Engineering Agent provides SEO audit tools for WordPress administrators, including crawl history, scoring, issue tracking, exports and monitoring dashboards.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/jm-seo-engineering-agent` directory.
2. Activate the plugin through the Plugins screen in WordPress.
3. Open the JM SEO Agent admin menu to launch a scan.
